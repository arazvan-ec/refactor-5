## Architecture Overview

```

├── Application/             # Application: Data transformers (write-read pattern)
│   └── DataTransformer/     #   Body elements, multimedia, journalists, apps
├── Orchestrator/            # Application: Chain of Responsibility orchestration
│   ├── Chain/               #   EditorialOrchestrator (main), Multimedia/*
│   └── Exceptions/          #   Chain-specific exceptions
├── Infrastructure/          # Infrastructure: Enums, Services (Thumbor, PictureShots), Traits

├── Exception/               # Domain: EditorialNotPublishedYetException

```

### Request Flow
```
GET /editorials/{id}
    → EditorialController
    → OrchestratorChainHandler
    → EditorialOrchestrator
        ├─ QueryEditorialClient (fetch editorial)
        ├─ QuerySectionClient (fetch section)
        ├─ QueryMultimediaClient (fetch multimedia) [ASYNC]
        ├─ QueryTagClient (fetch tags) [LOOP]
        ├─ QueryJournalistClient (fetch signatures) [LOOP]
        ├─ QueryMembershipClient (fetch membership URLs) [ASYNC]
        ├─ QueryLegacyClient (fetch comments)
        └─ MultimediaOrchestratorHandler
            ├─ MultimediaPhotoOrchestrator
            ├─ MultimediaEmbedVideoOrchestrator
            └─ MultimediaWidgetOrchestrator
    → DataTransformer Pipeline
        ├─ DetailsAppsDataTransformer
        ├─ BodyDataTransformer → BodyElementDataTransformerHandler
        ├─ MediaDataTransformerHandler
        ├─ JournalistsDataTransformer
        ├─ MultimediaDataTransformer
        ├─ StandfirstDataTransformer
        └─ RecommendedEditorialsDataTransformer
    → JSON Response (with cache headers)
```

### Patterns in Use

- **Strategy Pattern**: Type-specific data transformers registered via tags
- **Fluent Interface**: write()->read() pattern in transformers
- **Compiler Pass Registration**: Dynamic service registration via Symfony tags
- **Anti-Corruption Layer**: QueryLegacyClient wraps legacy API

## Known Patterns & Anti-Patterns

### Patterns to Follow
1. **Chain of Responsibility + Compiler Pass**: Register new handlers via tags, auto-discovered
2. **Write-Read Transformer**: write($data) configures, read() returns array
3. **Lazy Singleton Clients**: External clients as `lazy: true, shared: true`
4. **Domain Interface Aliasing**: Point domain interface to infrastructure implementation in YAML

### Anti-Patterns to Avoid
1. **God Object**: EditorialOrchestrator has 16+ dependencies and 536 LOC
2. **Trait-based Mixins**: MultimediaTrait/UrlGeneratorTrait hide dependencies
3. **Copy-paste Processing**: Inserted news and recommended editorials share identical logic
4. **Sync-on-Async**: Promises created but blocked with ->wait()
5. **N+1 Queries**: Sequential journalist lookups per signature
